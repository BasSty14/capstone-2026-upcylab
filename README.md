# Bitacora-UpcyLab
Repositorio oficial de UPCYLAB, un Proyecto Capstone enfocado en la sostenibilidad y circularidad. Nuestro objetivo es diseñar un prototipo técnicamente viable para reducir, reutilizar o reciclar los residuos de impresión 3D en resina y cortadora láser generados en la fabricación digital.
